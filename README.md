# 📌 Project Overview

This project develops an **Artificial Intelligence based temperature prediction system** using machine learning and deep learning techniques.

The system analyzes historical weather data such as:

- Humidity  
- Wind Speed  
- Atmospheric Pressure  

to accurately **predict future temperature values**.

Traditional forecasting methods struggle with nonlinear weather patterns, while AI models can learn these patterns and produce more reliable predictions.

---

# 🎯 Objectives

- Build an **AI based temperature prediction model**
- Analyze **historical weather datasets**
- Implement **Machine Learning and Deep Learning algorithms**
- Improve prediction accuracy using **data preprocessing and feature engineering**
- Compare multiple models to find the **best performing algorithm**

---

# 📊 Dataset Information

The dataset contains approximately **18,000 weather records** with the following features:

| Feature | Description |
|--------|-------------|
| Date | Weather observation date |
| Humidity | Amount of moisture in air |
| Wind Speed | Speed of wind |
| Atmospheric Pressure | Air pressure level |
| Temperature | Target variable |

Data preprocessing steps included:

- Handling missing values  
- Removing duplicate records  
- Outlier detection  
- Feature scaling

# 🧠 Machine Learning Models Used

### Linear Regression
Used as a baseline model to understand linear relationships.

### Random Forest
An ensemble learning model that improves prediction accuracy and reduces overfitting.

### Gradient Boosting
Boosting algorithm that minimizes prediction errors.

### Support Vector Regression (SVR)
Handles nonlinear relationships using kernel functions.

### LSTM (Deep Learning)
Long Short-Term Memory networks capture **time-series patterns in weather data**.
